# Как снимать и выпускать

## Запись

- **OBS**, 1920×1080, 60 fps, высокий битрейт. Потом кадрирование в вертикаль.
- Либо сразу вертикально: OBS-плагин Aitum Vertical — пишет 1080×1920 параллельно.
- **Тренировочный сервер** для раскидок: свой лобби-сервер, затем в консоли
  `sv_cheats 1; mp_roundtime_defuse 60; mp_freezetime 0; sv_infinite_ammo 1; sv_grenade_trajectory_prac_pipreview 1; mp_restartgame 1`.
- Для сравнений «10 lvl vs 1 lvl» — постановка с ботами или друзьями, либо фрагменты своих демок (`demoui`).
- Чистый HUD: `cl_drawhud 0` для красивых кадров результата, `cl_draw_only_deathnotices 1` — оставить только килфид.

## Монтаж (CapCut / DaVinci Resolve)

1. Первый кадр — результат (смок лёг, раунд выигран). Без вступлений и логотипов.
2. Крупный текст в первые 2 секунды, в безопасной зоне (не в нижних 20% и не справа — там кнопки YouTube).
3. Субтитры на всю речь: большая часть Shorts смотрится без звука.
4. Зум на перекрестие прицела, когда показываете раскидку.
5. Длина 15–35 с. Каждая секунда без нового действия — вырезать.
6. Финальный кадр = первый кадр (автоповтор).

## Загрузка

- YouTube Shorts → потом тот же файл на VK Клипы и Дзен.
- Время: 18:00 и 21:00 МСК, пока Studio не покажет своё.
- Через 48 часов — внести цифры в [tracker.csv](tracker.csv).

## Еженедельно (воскресенье, 30 минут)

1. Отсортировать трекер по «во сколько раз выше медианы».
2. Топ-3 ролика — что общего в первых 2 секундах? Делать больше этого.
3. Худшие 3 — где пролистывали? (Studio → «Смотрели / пролистали»).
4. Обновить [plan.md](plan.md) на следующую неделю.
5. Обновить реальные цифры в [calc.py](calc.py) и пересчитать срок до ПВЗ.
