# Freelance starter kit

Everything for getting your first international freelance orders as an
AI-assisted ("vibe") developer.

| File | What's inside |
|---|---|
| [profile.md](profile.md) | Profile title and description in English, skills, Fiverr gigs with prices, which platforms to use |
| [proposals.md](proposals.md) | Proposal templates for bots, scraping, automation, websites, plus client messages |
| [../portfolio/telegram-ai-bot](../portfolio/telegram-ai-bot) | Demo project 1: Telegram AI bot |
| [../portfolio/web-scraper](../portfolio/web-scraper) | Demo project 2: catalog scraper to CSV/JSON |

## 7-day plan

1. **Day 1.** Make this GitHub repo public (or copy the `portfolio` folder into a
   new public repo) so clients can open the links.
2. **Day 1.** Run the Telegram bot yourself and record a 20-second screen video.
   Take a screenshot of the scraper's CSV opened in Excel/Sheets.
3. **Day 2.** Register on Fiverr and create the two gigs from `profile.md`
   with those screenshots.
4. **Day 2–3.** Register on Upwork / Freelancer / Contra and fill in the profile.
5. **Every day.** Send 5–10 proposals using `proposals.md`, each with a personal
   detail from the job post. Pick small jobs ($20–150) first: they're easier to win.
6. **When you get a job.** Bring the client's task here; I'll build it with you.
7. **After delivery.** Ask for a review. After 5–10 reviews, raise prices.
